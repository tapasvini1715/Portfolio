# Tapasvini Portfolio Starter

## Open it
Double-click `index.html` to preview the site locally.

## Replace your photos
Create these files inside `assets/images/` and replace the placeholder blocks in the HTML with `<img>` tags:
- portrait.jpg
- momo-01.jpg
- travel-01.jpg
- food-01.jpg
- artwork-01.jpg
- etc.

Example:
```html
<img src="assets/images/portrait.jpg" alt="Tapasvini portrait">
```

## Update your links
Search the HTML files for `href="#"` and replace with your real LinkedIn, Instagram, GitHub, and resume links.
